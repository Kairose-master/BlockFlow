# 규칙 R1~R12 (packages/bpmn/src/parse.ts)

| # | 규칙 | 메시지 | 흔한 원인 |
|---|---|---|---|
| R1 | 시작 이벤트 정확히 1개, in 0, out 1 | 시작점은 하나여야 해요 | 시작 이벤트 복사 |
| R2 | 종료 이벤트 ≥ 1, out 0 | 끝나는 지점이 필요해요 | 종료 이벤트 없음 |
| R3 | 태스크 in 1 / out 1 | 태스크에서 갈라지거나 모으려면 마름모(게이트웨이)를 쓰세요 | 태스크에 화살표 2개 |
| R4 | 게이트웨이는 분기(in1,out≥2) 또는 합류(in≥2,out1) | 이 마름모는 갈라지거나 모으는 것 중 하나만 해야 해요 | 합류+분기 겸용 |
| R5 | XOR 분기: 조건 필수, 기본 플로우 1개 | 기본 화살표를 정하세요 / 조건이 없는 화살표가 있어요 | `default=` 누락 |
| R6 | AND 분기 플로우에 조건 없음 | 동시에 진행하는 화살표엔 조건을 붙일 수 없어요 | |
| R7 | 태스크는 레인 안 | 이 일은 누가 하나요? 역할 칸 안으로 옮기세요 | `flowNodeRef` 누락 |
| R8 | 시작→모든 노드, 모든 노드→종료 도달 | 도달할 수 없는 일이 있어요 | 끊긴 화살표 |
| R9 | 조건식 타입 검사, 변수 선언 | 조건에 쓰인 [x]는 아직 정의되지 않았어요 | `bc:variables` 누락 |
| R10 | 조건 변수는 이전 태스크 입력에서 설정됨 (모든 경로) | [금액]을 입력받기 전에 조건에서 쓰고 있어요 | `bc:inputs` 누락. AND 합류 뒤는 합집합 |
| R11 | 플로우 ≤ 256 | 프로세스가 너무 커요. 나눠 주세요 | |
| R12 | 이름 비어 있지 않음 (프로세스·태스크·레인) | 이름을 붙여 주세요 | |
| L0 | 팔레트 밖 요소 | 서비스 태스크(오라클)는 L1 에서 지원돼요 … | 타이머·메시지·서브프로세스 |

Soundness(1-safe·데드락·남은 토큰·dead task)는 IR 단계의 `packages/validator` 가 본다.

| L1 | 결제 태스크: 토큰 주소(0x…40자리), 받는 쪽(역할 키 또는 주소), 금액 변수(uint256, 이전에 입력됨) | 결제에 쓸 토큰 주소를 넣어 주세요 … | `bc:payToken`/`bc:payTo`/`bc:payAmountVar` 누락 |
| L1 | 타이머 경계 이벤트: 사용자 태스크에 부착, in 0 / out 1, 기한(값 uint256 초 또는 초 리터럴), 태스크당 1개 | 기한 이벤트는 할 일(사용자 태스크)에 붙여야 해요 … | `attachedToRef`·`bc:deadlineVar`/`bc:deadlineSeconds` 누락 |
| R12 | 변수 이름이 Solidity 예약어(days, seconds, ether …)이거나 생성 코드 지역 이름(id, m, v …) | '{name}' 은 쓸 수 없는 이름이에요 | `days` 대신 `leaveDays` |
| L1 | 서비스 태스크(bpmn:serviceTask): in 1 / out 1, 결제 불가, 레인 불필요. 응답값은 bc:inputs | 외부 서비스(오라클) 태스크에는 결제를 붙일 수 없어요 | — |
